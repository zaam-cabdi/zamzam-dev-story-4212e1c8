## 4. Visual Design System

Use a premium dark technology-inspired design.

**Color palette**
- Main background: #0B1020
- Secondary background: #111827
- Card background: #151E30
- Primary accent: #3B82F6
- Bright accent: #60A5FA
- Main text: #F8FAFC
- Secondary text: #94A3B8
- Borders: subtle blue-gray with low opacity

Use blue gradients sparingly for buttons, highlighted words, borders, and decorative lighting.

**Typography**

Use a modern sans-serif font such as Inter, Manrope, or Space Grotesk. Establish a clear hierarchy between large hero headings, section headings, card titles, and body text.

**Layout**

- Generous whitespace.
- Consistent spacing and alignment.
- Rounded cards with restrained shadows.
- Balanced use of text and imagery.
- Clean section transitions.
- Consistent buttons and iconography.
- Strong contrast for accessibility.

Avoid excessive neon effects, unnecessary gradients, cluttered layouts, and overly complicated animations.
